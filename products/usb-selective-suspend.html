USB selective suspend vs a forever loop

Published 2026-08-31 · 824 Consultants LLC · Windows Grok host playbook

This is not the Modern Standby page and not the USB Ethernet buy guide. Sleep-vs-forever is the laptop going to S0ix. Ethernet is the NIC hardware. This page is the USB power-policy layer that can sleep the NIC and the fallback hub while Task Scheduler still shows Ready and Grok still claims FULL AUTO.

The problem

Windows Balanced plan defaults USB selective suspend to Enabled. After idle, the OS asks the hub to power down. A dedicated USB NIC looks unplugged. GitHub MCP ships hang. A named hourly task fires into a host that has no Ethernet and a sleeping hub. The operator sees LEXXII-Materialize-Forever last-result 0 and assumes the loop is healthy. The ship never left the box.

This is not a Linux systemd issue. This Windows profile is not a cluster. Disabling selective suspend on the hub that carries Ethernet is a host setting, not a daemon.

What to change (plugged-in Grok desk)

  1. Power Options → Change plan settings → Change advanced power settings → USB settings → USB selective suspend setting — set Plugged in to Disabled. On battery can stay Enabled if this laptop actually travels. A desk that never unplugs should not pretend it is a travel cube.
  2. Device Manager → Universal Serial Bus controllers → USB Root Hub (the one feeding the NIC / fallback hub) — Properties → Power Management → uncheck Allow the computer to turn off this device to save power. Do this on the hub that actually carries Ethernet, not every hub on the machine.
  3. Confirm the NIC is still Present after 30 minutes idle — PowerShell: Get-PnpDevice | Where-Object { $_.FriendlyName -match 'Ethernet|Realtek|ASIX|USB' -and $_.Status -eq 'OK' }. If the dedicated NIC vanished, selective suspend or a dock reset still owns the desk.
  4. Do not disable PCI Express Link State Power Management as a cargo-cult — that is a different layer. Fix USB first. If Wi-Fi is the only remaining path, you still failed the dedicated NIC test.
This page does not claim a setting is already applied on every Windows Grok host. It is the click path. Operator still owns the laptop. Agents do not invent a group-policy fleet.

Soak test (what "passes" means)

  1. Leave the desk idle 30 minutes, lid closed, cooling stand in place, Ethernet plugged. Ping a public host from the USB NIC. One silent gap is a fail.
  2. Confirm Task Scheduler still has a next-run for LEXXII-Materialize-Forever. A Ready task with a dead NIC is not forever.
  3. Unplug/replug the dock as in a brown-out. NIC must return without a Device Manager hunt.
