Display brightness on AC vs a forever loop

Published 2026-08-31 · 824 Consultants LLC · Windows Grok host playbook

This is not the Turn off display after page, not Enable adaptive brightness, and not a DisplayPort cable review. VIDEOIDLE is the off timer. Adaptive brightness is the ALS hunt. The cable is hardware. This page is the remaining percentage: Power Options → Display → Display brightness on AC. A leftover 20–40% makes the laptop panel look dead. Display settings still lists it. Task Scheduler still shows Ready. A dim panel is not a DP unplug.

The problem

The sleep-vs-forever pack already tells you plugged-in sleep is not 5–20 minutes. Turn off display after can already be 0 (Never) on AC. That work can be done and the desk still looks like video died. Balanced or a restored plan can leave Display brightness on AC at a battery leftover — 20, 30, or 40 percent. Settings → System → Display → Brightness (internal) matches that leftover. The laptop lid looks off. The Grok TUI is still a process on a live desktop. Dual ultrawide still enumerate. The named task still prints Ready and last result 267009 (still-running). The operator thinks the DP lead failed. A percentage napped the backlight. The link never dropped.

This is not Sleep. This is not VIDEOIDLE. A black panel with a handshake and a dock re-enumerate is the off timer — that is turn-off-display-after. This page is dim, not black. powercfg /a still reports the same standby type. Requests can still be None. VIDEOIDLE can still be 0. Display settings still shows the same screens. The brightness policy is the liar. Do not install systemd to paper over 40 percent. Do not mint a Vercel slug because a lid looked dark. Do not buy another DP cable for a panel that is still in Device Manager.

What to change (plugged-in Grok desk)

  1. Confirm the session and off-timer layers are already done — plugged-in sleep / hibernate are not 5–20 minutes. Lid close on AC is Do nothing. Turn off display after is 0 on AC. If the desk still intends to sleep or black the panels every idle, stop here. A dim soak on a black timer is a lie.
  2. Power Options → Change plan settings → Change advanced power settings → Display → Display brightness — set Plugged in to the working AC level. On this class of operator desk that is typically 80–100. On battery may stay 20–40 if this laptop actually travels. A desk that never unplugs should not inherit the DC copy. Settings → System → Display → Brightness (internal) is the same percentage on most laptops; the Quick Settings slider is the same internal backlight. They should agree on AC.
  3. Leave Turn off display after and Console lock display off alone on this click — those are off timers. Dim is not off. Do not treat a black handshake as this row.
  4. Leave Enable adaptive brightness alone on this click — that is ADAPTBRIGHT, the ALS hunt. Off or On is a sibling page. Dragging this percentage does not disable the sensor.
  5. Leave Energy saver alone on this click — Always use energy saver can still cut ~30% on top of an honest percentage. That overlay is not VIDEONORMALLEVEL. If the leaf is on, the overlay is the liar, not this row.
  6. Leave the Balanced (or current) plan in place — this page is one display percentage, not a switch to High performance. Do not rename the plan. Do not claim a fleet GPO. Do not Apply all on Energy recommendations; that card can smash sleep and display timers.
  7. Confirm, then soak — query VIDEONORMALLEVEL. AC should match the set working level, not a leftover 0x14 / 0x28 (20 / 40). If the alias is missing, stop. Do not invent a registry hack on a public page. Do not paste live brokerage numbers next to that output. Do not paste auth.json.
powercfg /query SCHEME_CURRENT SUB_VIDEO VIDEONORMALLEVEL
powercfg /query SCHEME_CURRENT SUB_VIDEO VIDEOIDLE
powercfg /a

SUB_VIDEO / VIDEONORMALLEVEL is the Display brightness row (0–100; the query speaks hex). 0x64 on AC is 100. 0x50 is 80 — a pass if that is the operator’s set OLED level. 0x28 or 0x14 on AC is 40 or 20 — a DC leftover or Energy-recommendations smash, not a pass on this desk. VIDEOIDLE remaining 0 on AC only proves the off timer; it does not prove this percentage. Adaptive brightness is ADAPTBRIGHT, not this click. External DP/HDMI panels often ignore this Windows percentage and keep their own OSD backlight — a dim ultrawide with a live identity in Display settings is still a live link. If powercfg omits VIDEONORMALLEVEL, this edition did not expose the knob — stop; hidden is not 100.

Soak test (what "passes" means)

  1. Sleep and lid already honest. VIDEOIDLE already 0 on AC. Otherwise this soak is lying about off vs dim.
  2. Leave the desk idle 30 minutes, lid closed, dedicated NIC plugged, dual ultrawide up. Internal panel (or any Windows-driven backlight) still matches the set AC level — not a surprise 20–40. Display settings still shows the same screens. Taskbar still exists on the dim-looking lid if the lid is in the mix.
  3. A dim panel is not a DP unplug. Fail this soak only if the percentage was the liar. A black-then-handshake on first input with a dock re-enumerate is a VIDEOIDLE fail, not this page. Do not buy a DP cable because the laptop lid looks dark.
  4. Task Scheduler still has a next-run for LEXXII-Materialize-Forever. Ready + 267009 with a 40% leftover on AC is not forever. Host-forever on this Windows profile is that named task. Grok in-session schedulers still expire in 7 days even when durable — recreate them if missing. Do not claim the Windows task is a Linux systemd unit.
  5. No fourth Grok TUI. Last result 267009 is still-running, not proof AC brightness is already honest.
