USB Root Hub power vs a forever loop

Published 2026-09-01 · 824 Consultants LLC · Windows Grok host playbook

This is not the USB selective suspend page and not the USB 3 LPM page. Selective suspend is the Power Options plan policy. USB 3 LPM is SuperSpeed U1/U2. This page is the Device Manager checkbox on the USB Root Hub that actually carries Ethernet.

Download markdown

The problem

USB selective suspend can already be Disabled on AC. The dedicated NIC still vanishes after idle. Device Manager → USB Root Hub → Power Management still has Allow the computer to turn off this device to save power checked. That is a per-device PnP flag, not the plan policy. LEXXII-Materialize-Forever still prints Ready. The hub that feeds Ethernet is already off.

Do not uncheck every hub on the laptop. The hub that carries the NIC or the fallback dongle is the liar. Do not install systemd. Do not mint a Vercel slug because a hub blinked.

Click path (plugged-in Grok desk)

  1. Confirm USB selective suspend is already Disabled on AC — if it is still Enabled, stop. That is usb-selective-suspend.html.
  2. Device Manager → Universal Serial Bus controllers → USB Root Hub (the one feeding the dedicated NIC / fallback hub) → Properties → Power Management → uncheck Allow the computer to turn off this device to save power.
  3. Leave USB 3 LPM and PCIe ASPM alone on this click — SuperSpeed and ASPM are other pages.
  4. Soak 30 minutes idle — NIC stays Present. Named task still has a next-run. One silent Device Manager hunt is a fail on this page.
