Power button action vs a forever loop

Published 2026-09-01 · 824 Consultants LLC · Windows Grok host playbook

This is not the lid close page, not the sleep vs forever page, and not hybrid sleep. Lid is the hinge. Timeouts are idle. Hybrid sleep is the Sleep row. This page is the remaining hardware key: Power Options → Power buttons and lid → Power button action. That is PBUTTONACTION. Balanced AC is often Sleep. A brush of the chassis key is Standby. Interactive-only LEXXII-Materialize-Forever misses the hour. Task Scheduler still shows Ready.

Download markdown Lid close first Sleep vs forever

The problem

The lid-close pack already tells you plugged-in lid action is Do nothing. Sleep timeouts can already be Never. That work can be done and one press still kills the loop. Balanced Power button action on AC is Sleep. A closed-lid Ultra 7 on a cooling stand still has a power key on the chassis or a dock button that maps to the same action. The operator leans, the stand shifts, the key clicks. Windows Sleeps. grok.exe pauses. The named task still prints Ready and last result 267009 (still-running). The operator thinks lid-close lied. A different button did the Sleep.

This is not lid-close. Lid is LIDACTION. This is PBUTTONACTION. Do not set Shut down as a “fix.” Do not Hibernate the forever desk from a bump. Do nothing on AC is the pass. On battery may stay Sleep if this laptop actually travels. Do not install systemd to paper over a chassis key. Do not mint a Vercel slug because a press looked like a dead task.

What to change (plugged-in Grok desk)

  1. Confirm lid-close on AC is already Do nothing — if closing the lid still Sleeps, that is lid-close, not this page.
  2. Confirm sleep timeouts are already honest — plugged-in sleep / hibernate are not 5–20 minutes. See sleep-vs-forever.
  3. Power Options → Change plan settings → Change advanced power settings → Power buttons and lid → Power button action — set Plugged in to Do nothing. On battery may stay Sleep if this laptop actually travels.
  4. Leave Sleep button action as a sibling — if this chassis has a dedicated Sleep key, that is SBUTTONACTION, not this click. Do not treat it as Power button action.
  5. Leave the Balanced (or current) plan in place — this page is one button knob, not a switch to High performance. Do not rename the plan. Do not claim a fleet GPO.
  6. Confirm, then soak — query the buttons subgroup. Do nothing on AC is the pass. Do not paste live brokerage numbers. Do not paste auth.json.
powercfg /query SCHEME_CURRENT SUB_BUTTONS
powercfg /a

SUB_BUTTONS is Power buttons and lid. PBUTTONACTION is Power button action. Typical values: 0 = Do nothing, 1 = Sleep, 2 = Hibernate, 3 = Shut down. 0 on AC is the pass for this desk. If the row is missing from the GUI, query with powercfg anyway — hidden is not the same as Do nothing. If powercfg also omits the alias, this firmware did not expose the knob — stop; do not invent a registry hack on a public page. Lid action is a sibling, not this click. Sleep button action is a sibling, not this click.

How it splits from the other playbooks

  • Lid close Do nothing — hinge action (LIDACTION). This page is the chassis/dock power key (PBUTTONACTION).
  • Sleep vs forever — idle timeouts. Not a button.
  • Allow hybrid sleep — whether Sleep writes a hiberfile. Not which button starts Sleep.
  • Fast Startup — hybrid shutdown from Start menu. Not the power key while running.
  • This page — AC Power button action = Do nothing so a bump cannot Sleep an Interactive Grok CLI while the named task still looks Ready.

Soak test (what "passes" means)

  1. Lid already Do nothing on AC. Sleep timeouts already honest. Otherwise this soak is lying about which button fired.
  2. Press the chassis power key once, lid closed, dedicated NIC plugged. The session stays awake. The Grok TUI still accepts input. Sleep or a black panel is a fail.
  3. Task Scheduler still has a next-run for LEXXII-Materialize-Forever. Ready + 267009 after a power-key Sleep is not forever.
  4. AC index still 0. If someone set Sleep to “have a real off switch,” restore Do nothing. Use Start-menu Shut down when you mean off — after Fast Startup is honest.
  5. No fourth Grok TUI. Last result 267009 is still-running, not proof the power key is already Do nothing.
