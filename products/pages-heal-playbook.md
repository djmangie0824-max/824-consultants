## What this pack is
The order of operations when GitHub Pages still looks fine while `main` has already been gutted. Use it when an agent "locks" the public face in the name of privacy.

## Standing split
| Surface | Rule |
|---|---|
| Home, autonomy, products hub, reviews, sitemap, robots | Public. Original. Disclosed. Crawlable. |
| `/vault`, desk, console, organism, IBKR figures, tokens | Owner-only. Deny wall is correct. |

Locking the catalog is not how you protect the vault.

## Incident A — PLACEHOLDER overwrite
Symptom: `index.html` on `main` is eleven bytes, title gone, Pages still serving the last good artifact.  
Cause: `create_or_update_file` with content `PLACEHOLDER` (or any stub) on the hub.  
Heal:
1. Do not push another stub.
2. Restore the full immersive hub (`Touch. Talk. Go.` + `canvas#field`) in one commit.
3. Validate locally: hub title, canvas, Associates disclosure, FULL AUTO strings on autonomy.
4. Push via `push_files` or git. Never use PLACEHOLDER as a SHA bump.

## Incident B — Law-237 public-face gut
Symptom: `robots.txt` becomes `Disallow: /`, sitemap empties, products/autonomy become "Private property" deny walls, home strips to essay chrome so `grep Touch. Talk. Go.` still passes.  
Cause: an agent treated the public LLC face as the vault.  
Heal:
1. Restore immersive hub, autonomy FULL AUTO page, product hub, `Allow: /`, populated sitemap.
2. Leave `/vault` as the deny wall.
3. Add validate gates: `canvas#field` on home, products hub must not be a deny wall, robots must allow crawl.
4. Confirm live `DEPLOY_STAMP.json` SHA after Actions succeeds.

## Incident C — CDN lag
Symptom: live site still shows the last good SHA while `main` is already bad. Deploys of the bad tree failed validate — that failure is the fuse.  
Heal: do not celebrate the live CDN. Repair `main` before the next green deploy publishes the gut.

## Daily check (2 minutes)
- [ ] Home is immersive, not a deny card
- [ ] Autonomy still has `Fully autonomous public surface` and `Zero human input required`
- [ ] Products hub lists live packs, not "unsigned visitors see this wall"
- [ ] robots allows crawl; sitemap has public URLs
- [ ] Vault is still sealed
- [ ] No NLV, cash, tickers, or account IDs on Pages
