This is not the Minimum processor state page, not the Processor performance boost mode page, not the Intel Speed Shift / EPP page, and not the core parking page. Min-state is the frequency floor. Boost is the turbo allow. EPP is a 0–100 hardware hint. Parking is the unparked-core floor. This page is the remaining software ceiling: Power Options → Processor power management → Maximum processor state. That is PROCTHROTTLEMAX. The problem

The four sibling knobs can already be honest on AC. Frequency floor 100. Unparked cores 100. Turbo allowed (Enabled). Speed Shift EPP 0. The TUI still starves. Maximum processor state is a hard percent cap on P-states in the same subgroup. That is PROCTHROTTLEMAX. It is not a hint. Forum folklore drops it to 99 to kill turbo without touching PERFBOOSTMODE. OEM “Cool” / “Quiet” / “Battery” Balanced plans drop it to 50–80 and stay selected after the laptop is docked. Enabled boost under a 99% ceiling is still a capped desk. EPP 0 under an 80% ceiling is still a capped desk. Floor 100 under a 99 ceiling is still a cap. grok.exe is alive. The named task still prints Ready and last result 267009 (still-running). The operator thinks the loop died. The ceiling was 99.

This is not sleep. powercfg /a still reports the same standby type. Requests can still be None. PROCTHROTTLEMIN can still be 100. CPMINCORES can still be 100. PERFBOOSTMODE can still be Enabled. PERFEPP can still be 0. The throttle ceiling is the liar. Do not install systemd to paper over a 99% cap. Do not mint a Vercel slug because the TUI paused. Do not switch the whole plan to High performance to hide five other forever-loop bugs. Do not confuse this PPM percent with the Task Manager Details “Power throttling” column — that is a process overlay, not PROCTHROTTLEMAX.

How it splits from the other playbooks

  • Minimum processor state — frequency floor (PROCTHROTTLEMIN). That pack tells you not to drop the ceiling and then stops. This page is the ceiling (PROCTHROTTLEMAX). Floor 100 under a 99 ceiling is still a cap.
  • Core parking — unparked-core floor (CPMINCORES). Parking is not a P-state percent. Unparked cores can still run under an 80% cap.
  • Processor performance boost mode — turbo allow (PERFBOOSTMODE). Enabled turbo with a 99% ceiling still cannot take the top bin. Not the same click.
  • Intel Speed Shift / EPP — 0–100 hardware hint (PERFEPP). A hint under a hard 80% cap is still a capped desk. Zero EPP does not replace 100 max-state. 100 max-state does not replace zero EPP.
  • System cooling policy — Passive vs Active fans. Thermal policy, not the software ceiling.
  • This page — AC Maximum processor state = 100 so an OEM 99% quiet-turbo trick or 80% travel ceiling cannot starve an Interactive Grok CLI while the named task still looks Ready.
