Hardware-accelerated GPU scheduling vs a forever Grok desk

Published 2026-09-01 · 824 Consultants LLC · Windows Grok host playbook

This is not the processor boost mode page, not Intel Graphics panel power, not system cooling policy, and not PCIe ASPM. Boost is CPU turbo. Intel panel power is the iGPU encoder nap. Cooling policy is fans vs throttle. ASPM is the PCIe link. This page is the remaining WDDM click: Settings → System → Display → Graphics → Default graphics settings → Hardware-accelerated GPU scheduling (HAGS). The GPU’s hardware scheduler takes command-buffer work the OS used to queue. It is a reboot click. It does not unstick GitHub MCP. Task Scheduler can still show Ready.

The problem

The boost, Intel panel, cooling, and ASPM packs can already be honest on AC. VIDEOIDLE can already be Never. The named Windows task still prints Ready and last result 267009 (still-running). After a Windows Update or a vendor driver drop, the compositor hitch, a copy stall, or a TDR toast shows up. grok.exe looks hung. The operator thinks GitHub MCP died, mints a Vercel slug, or pastes a GPU-Z dump with a board serial onto a public page. Wrong layer. Hardware-accelerated GPU scheduling flipped, or never applied because nobody rebooted.

HAGS is WDDM 2.7+ handing GPU scheduling to the adapter. On a forever Grok desk the GPU is mostly the display engine, not a game. On can cut CPU overhead of the software scheduler. On can also hitch a mixed iGPU+dGPU compositor. Off can be the honest desk if On was the stutter. Neither state unblocks a Contents PUT. Neither state is PERFBOOSTMODE. The liar is an unknown, unrebooted HAGS state blamed on Git.

This is not Sleep. powercfg /a still reports the same standby type. Requests can still be None. Do not install systemd to paper over a WDDM toggle. Do not invent a driver SKU. Do not cargo-cult On as “always faster” or Off as “always safer.” The forever desk wants a known rebooted state, Settings matching the registry, and a skip when the toggle is missing.

What to change (plugged-in Grok desk)

  1. Confirm the earlier layers are already done — plugged-in sleep is not 5–20 minutes. Lid close on AC is Do nothing. ASPM Off on AC. Intel panel power already honest if an Intel adapter exists. Cooling policy Active on AC. Boost not Disabled on AC. See pcie-link-state-power, intel-graphics-panel-power, system-cooling-policy, and processor-boost-mode.
  2. Settings → System → Display → Graphics → Default graphics settings — some builds say Change default graphics settings. Look for Hardware-accelerated GPU scheduling. If the row is missing, this Windows edition or this GPU/driver did not expose HAGS. Stop. That is a skip, not a fail.
  3. Set a known On or Off — then reboot — the forever desk wants a documented state, not a mid-session flip. Do not cargo-cult On because a forum said RTX requires it. Do not cargo-cult Off because a game stuttered on a different SKU. If On is hitching the compositor on this mixed iGPU+dGPU desk, Off + reboot is the honest try. If Off is already the known state and the display stack is already honest, do not flip On hoping a Contents PUT recovers. Leave Variable refresh rate and Optimizations for windowed games as siblings.
  4. Leave per-app Graphics, NVIDIA/AMD control panels, and Hardware-accelerated GPU scheduling’s neighbors alone on this click — app GPU preference is not HAGS. Do not invent a vendor SKU. Do not switch the Windows plan to High performance to hide a WDDM toggle.
  5. Read-only confirm after reboot — HwSchMode under HKLM\SYSTEM\CurrentControlSet\Control\GraphicsDrivers. 1 = off. 2 = on. Settings is the live tell. Registry is the confirm. If the value is missing after a missing Settings row, that is the same skip. Do not New-ItemProperty. Do not reg add. Do not paste a .reg file on this public page.
  6. Leave GitHub MCP, PAT, and GCM alone — a HAGS reboot does not mint a token and does not un-hang Git Credential Manager. Credential 401 is still 401.
  7. Soak — named task still next-runs. TUI still accepts input. Settings still matches HwSchMode. Do not paste live brokerage numbers. Do not paste auth.json. Do not paste GPU-Z serials.

Soak test

  1. Boost, cooling, Intel panel power, and ASPM already honest on AC. Otherwise this soak is lying about CPU, encoder, or link.
  2. If the HAGS row is missing, the soak is a skip, not a red. Do not create HwSchMode.
  3. If the row exists: Settings On or Off matches HwSchMode 2 or 1 after reboot. A Settings flip with no reboot is not a pass.
  4. Idle past a few minutes. Compositor still paints. TUI still accepts input. Named task still has a next-run for LEXXII-Materialize-Forever. Ready + 267009 is still-running, not proof HAGS is already known.
  5. GitHub MCP still 401 after a clean HAGS reboot is still a credential miss. This page did not fail. Do not mint a Vercel slug. Do not open a fourth Grok TUI.
