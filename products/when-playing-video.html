When playing video vs a forever loop

Published 2026-09-01 · 824 Consultants LLC · Windows Grok host playbook

This is not the When sharing media page. Sharing can pin SYSTEM or AWAYMODE with no player on screen. This row is the other Multimedia setting: When playing video — Windows alias VIDEOQUALITY. It is a playback-quality bias. It is not a share policy, not Sleep after, and not a named hourly. A 10-hour rain video in a background tab is cargo-cult keep-awake. It is not LEXXII-Materialize-Forever.

The problem

Balanced already exposes Multimedia settings → When playing video with three indexes. Optimize video quality (0) tells Windows to bias the GPU and the panel toward playback: a decoder may hold DISPLAY for as long as frames are actually moving. Balanced (1) is the honest plugged-in Grok desk. Optimize power savings (2) lets playback yield to the display idle timer. None of those three values run the hourly. None of them replace sleep-vs-forever timeouts. None of them are When sharing media.

The trap is a looping keep-awake: YouTube “10 hours,” lo-fi, a paused Movies & TV window, Edge picture-in-picture, a minimized VLC playlist, a browser tab that never finished the last preview. Optimize video quality plus that loop makes dual ultrawide look immortal. Task Scheduler still shows Ready. Last result 267009 still means still-running. The operator thinks host-forever is a video. It is a DISPLAY request from a player. Close the decoder and the hold should drop. If DISPLAY stays named after stop, that is powercfg /requests — leftover GPU process, not this row.

VIDEOIDLE can already be Never and a looping tab still pins the panel. That is this page, not Turn off display after. Sharing can already be Allow and a looping tab still pins DISPLAY. That is this page, not the share policy. Do not install systemd to paper over a rain video. Do not mint a Vercel slug because a tab held the GPU.

What to change (plugged-in Grok desk)

  1. Confirm the timeout layer is already done — plugged-in sleep / hibernate are not 5–20 minutes. Lid close on AC is Do nothing. Display idle is honest if that pack already shipped. See sleep-vs-forever.
  2. Confirm the share row is not this click — When sharing media on AC is already Allow the computer to sleep. If it is still Prevent or Away Mode, stop and open When sharing media. Do not restamp that page as this one.
  3. Power Options → Change plan settings → Change advanced power settings → Multimedia settings → When playing video — Plugged in = Balanced. Not Optimize video quality as a keep-awake. Battery may stay Optimize power savings if this laptop actually travels. A desk that never unplugs should not pretend a rain video is UPS.
  4. Stop the cargo-cult decoder — close the looping tab, PiP, Movies & TV, VLC, and any “keep PC awake” playlist. A real product preview may hold DISPLAY while it plays. That is expected. The hold must clear when you stop. Host-forever is the named Windows task, not a decoder.
  5. Confirm with requests — idle session, no decoder. DISPLAY prints None. Then soak. Do not paste live brokerage numbers next to that output. Do not paste auth.json.
powercfg /query SCHEME_CURRENT SUB_VIDEO VIDEOQUALITY
powercfg /q SCHEME_CURRENT SUB_MULTIMEDIA
powercfg /requests

VIDEOQUALITY is the When playing video row (GUID 34C7B99F-9A6D-4B3C-8DC7-B47F6AC43933 under the Multimedia / video subgroup). AC index 1 is Balanced — the pass for this desk. 0 is Optimize video quality. 2 is Optimize power savings. GUI path above still applies if the alias is hidden; some SKUs only show the friendly names. Empty /requests DISPLAY after Balanced, with no decoder, is the pass. A leftover DISPLAY holder with Balanced already set and the player closed is a vendor / browser GPU leftover — go back to requests and name the PROCESS. If powercfg omits VIDEOQUALITY, this edition did not expose the knob — stop; do not invent a registry hack on a public page.

Soak test (what "passes" means)

  1. Sleep timeouts already honest on AC. Sharing media already Allow. Otherwise this soak is lying about the wrong row.
  2. When playing video on the plugged-in plan is Balanced, not Optimize video quality.
  3. No looping keep-awake tab. Idle session, no decoder. powercfg /requests prints None under DISPLAY.
  4. Start a real short preview if you have one. DISPLAY may name the player while frames move. Stop the preview. DISPLAY returns to None. A holder that survives “stop” is a leftover process, not this row.
  5. No fourth Grok TUI. Last result 267009 is still-running, not proof a rain video is the hourly.
