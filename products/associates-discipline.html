Gate before a tagged URL exists

  1. The commercial page already carries the FTC sentence: As an Amazon Associate I earn from qualifying purchases.
  2. A problem-first write-up exists on this property. Criteria before SKU.
  3. We would still name that class at zero commission.
  4. The destination URL was minted while signed in as the Associates account, and the query string contains tag=824consultant-20 — not a guessed tag, not a truncated amzn.to with no tag.
  5. The anchor uses rel="nofollow sponsored".
  6. Associates Central reports stay off Pages. Never “this SKU already earned $X.”
A review card that still says SKU pending does not get a tracking URL invented to “complete the catalog.” Pending is honest. A fake tag= is Incomplete Delivery.
