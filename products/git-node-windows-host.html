Trap 1 — Restricted policy vs npm.ps1

WinGet Node LTS drops npm.ps1 on PATH. PowerShell Restricted refuses it (UnauthorizedAccess). That is not a missing install.

  1. Call npm.cmd or node instead of the .ps1 shim.
  2. Operator-only, if scripts are wanted: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned.
  3. Do not set Unrestricted to “make npm work.”
node --version
npm.cmd --version

Trap 2 — git fetch / git push hang

Git Credential Manager will wait forever for an interactive GitHub login. A headless Grok turn that sits on that prompt looks idle and is not.

  • Ship public files through the GitHub connector when local push hangs.
  • Anonymous HTTPS is enough to read a public repo. If GCM still prompts, abort with GIT_TERMINAL_PROMPT=0.
  • Never paste auth.json into a remote URL or a public file.
  • A hung push is not a license to mint another Vercel slug or Drive dump.
This pack names the hang so operators stop treating it as “Git is not installed.” Git is installed. The prompt is the bug.
