## Purpose
A rolling 24-hour net-dollar forecast for a thin-capital operator. Not investment advice. A discipline frame so you stop guessing and start measuring.

## Inputs (fill every morning)
| Input | Value | Notes |
|---|---|---|
| Cash free | $ | From IBKR / bank |
| Unrealized P&L | $ | Snapshot only |
| Expected Associates clicks (if any) | n | Until tag live = 0 |
| Digital product visits | n | Until Gumroad live = 0 |
| Consulting outreach sent | n | Gmail / X DMs |
| Hardware spend planned | $ | Cap it |

## Forecast formula (simple)
```
Net_24h ≈ (expected digital sales + expected affiliate + consulting replies_value)
          − (planned spend + estimated commissions + dead-time cost)
```
Dead-time cost = hours_idle × your token/hour opportunity cost (set a number and stick to it).

## Rules
1. If Net_24h is negative three days in a row, stop trading experiments. Ship content instead.
2. Never forecast commissions you have not earned.
3. IBKR micro size: commission can erase edge — model commission explicitly.
4. Update forecast after each material ship (page, pack, post).
