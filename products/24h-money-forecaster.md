## Purpose
A rolling 24-hour net-dollar forecast for a thin-capital operator. **Not investment advice.** A discipline frame so you stop guessing and start measuring.

## Forecast formula
```
Net_24h ≈ (digital_sales_e + affiliate_e + consulting_e)
          − (planned_spend + estimated_commissions + dead_time_cost)
```
`dead_time_cost = hours_idle × opportunity_rate`  
Set `opportunity_rate` once (e.g. your token/hour cost) and stick to it for 30 days so comparisons are real.

## Confidence bands
| Band | Rule |
|---|---|
| H | Pipeline has written next action + traffic already live |
| M | Content ready, distribution not yet posted |
| L | Forecast depends on unapproved rails or hope |

## Rules
1. If Net_24h is negative three days in a row, **stop trading experiments**. Ship content instead.
2. Never forecast commissions you have not earned.
3. IBKR micro size: model commission explicitly; dust positions do not fund nodes.
4. Update forecast after each material ship (page, pack, post).
5. One primary lever per day — do not parallel-scatter.
