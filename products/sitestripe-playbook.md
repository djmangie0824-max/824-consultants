## One-time click path
1. Sign into Amazon.com with the same customer account that owns Associates Central for 824 Consultants LLC. SiteStripe only appears when Amazon recognizes that session.
2. Open Associates Central → **Tools** → **SiteStripe**.
3. Under Display Options, set SiteStripe **ON**. If it is already ON, do not toggle it off.
4. Stay signed in and open a product detail page that already passed the zero-commission honesty gate (would we still recommend it at $0 commission?).
5. Use **Get Link → Text**. Confirm the generated URL contains `tag=824consultant-20`.
6. Paste that URL onto the matching review card with `rel="nofollow sponsored"` and the standing disclosure.
7. Spot-check: click the live Pages link, read the destination query string, confirm the tag. Do not ask an agent to guess a tracking URL.
