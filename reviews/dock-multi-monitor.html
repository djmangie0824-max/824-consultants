Underspec docks drop displays under load. Criteria for docks with honest PD budget, DisplayPort alt-mode truth, and stable firmware.

The job, not the SKU

We care about four outcomes only:

  1. Two displays stay up under simultaneous load.
  2. Power delivery numbers are honest when displays + storage share the dock.
  3. Firmware updates do not brick the unit.
  4. Upstream bandwidth is enough for displays + external NVMe / cameras.

What we actually check

  1. PD budget under load — marketing 100W means nothing if displays steal the budget.
  2. Chipset / firmware path — no mystery chips with dead support pages.
  3. Port map clarity — which ports share bandwidth lanes.
  4. Would we still use with no commission? Only if it survives a full operator desk day.
If the product page refuses to specify lane sharing or PD under dual display, it fails.
