USB-C GaN charger that holds a 14h Grok CLI laptop

Published 2026-08-31 · 824 Consultants LLC · Problem-first operator notes

This is not the desktop PSU page and not the USB-C hub page. Those cover dual-GPU wall power and port starvation. This page is the laptop brick: the thing that either keeps a Windows Grok CLI host at 20V, or quietly lets the pack drain while you think you are plugged in.

The problem

A 14-hour operator session on this class of laptop is not idle web browsing. Grok CLI, a browser of research tabs, local model load, and at least one display over USB-C will pull more than the OEM 65W travel brick can replenish. The battery graph slopes down. Fans ramp. PD renegotiates from 20V to 15V or 9V when a second device shares the brick. The session ends because the host dies, not because the work was done.

Cheap “100W” GaN cubes print 100W on the box and 65W on the only port that is actually occupied. The cable is often a 60W non-e-marked lead in the same SKU photo. Docks that already move video plus NVMe cannot be the only PD source. Two PD sources fighting on one Type-C controller is worse than one honest brick.

The job, not the SKU

We care about five outcomes only:

  1. The host maintains or gains charge under Grok CLI + local-AI load, not just at the login screen.
  2. The brick publishes a per-port table under simultaneous load, not a summed fantasy.
  3. The cable in the kit (or the one we name) is 5A e-marked for 100W-class PD.
  4. Heat stays desk-usable for 14 hours. A cube that throttles after 40 minutes fails the same as a weak OEM brick.
  5. We would still buy it with zero commission.

Verdict criteria

  1. Wattage honesty — total and per-port, with two devices attached. “2×100W” that collapses to 65W+30W is a fail unless that split still holds the laptop.
  2. PD profile match — USB Power Delivery 3.0 (PPS welcome) with a 20V path this laptop class actually negotiates. Phone-only PPS bricks that never offer 20V are out.
  3. One dedicated host port — the laptop does not share its 100W-class port with a phone. Second port is overflow, not a tax on the session.
  4. No PD fight — either the dock feeds the host, or the GaN brick does. Not both. Not through the over-subscribed hub from the fallback-hub notes.
  5. Thermal + fold-flat — brick stays on the desk, cable reaches the host without lifting a standing-desk cable run into a snag.
If the listing hides the shared-load table, ships a 60W cable with a 100W claim, or only shows phone charge graphs, it fails the honesty gate and does not earn a tagged link.

Architecture we recommend

  • Desk, dual display: dock PD to the host if the dock actually holds charge (see the multi-monitor dock notes). GaN brick stays in the bag as the known-good path when dock PD sags.
  • Long CLI / travel / overflow: GaN brick on the laptop’s own USB-C charge port. Hub and capture devices stay on a separate powered path.
  • Never: daisy-chain the charger through a mystery hub that is already moving storage and video. Never two PD sources on one controller.
  • Measure: Windows battery report or the OEM power meter over a two-hour Grok CLI soak. If percent falls while “plugged in,” the brick failed — marketing watts do not matter.
