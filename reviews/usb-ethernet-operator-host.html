USB Ethernet that keeps a Windows operator host on the wire

Published 2026-08-31 · 824 Consultants LLC · Problem-first operator notes

This is the wall-side network for a Windows Grok CLI desk. It is not a WiFi 7 marketing page. A laptop that “has internet” on a 2.4 GHz guest SSID will still drop the GitHub connector mid-ship. Local git push then hangs on credentials, and the turn looks idle.

The problem

WiFi power-save is a silent ship killer. The radio sleeps. TLS to api.github.com stalls. Git Credential Manager waits for a prompt nobody will see. Grok MCP tools report empty. The operator thinks Git is missing. Git is installed. The radio left.

USB-C docks that include “gigabit Ethernet” often share a Realtek bucket with a hub that already enumerates storage and a display. When the dock brown-outs (see the UPS page) the NIC dies with the displays. A dedicated USB Ethernet dongle on a powered hub is a different failure domain.

Verdict criteria (before any SKU link)

  1. USB 3.x dedicated NIC, not a dock checkbox — if the adapter lives inside the same dock that supplies PD, it is not a fallback.
  2. Windows 11 inbox or WHQL driver — no unsigned Realtek hunt on a Grok host. If Device Manager wants a CD, fail.
  3. Link stays up across Modern Standby — S0 sleep that drops DHCP is the same class of bug as the sleep vs forever playbook.
  4. Does not reset the hub — plugging it in must not re-enumerate the NVMe or the Yubi-class key next to it.
  5. Honest 1G is enough — 2.5G banners do not fix a WiFi drop. Do not pay for multi-gig to push HTML.
  6. Would we rebuy at $0 commission? — only then does a product card open. Tag 824consultant-20 never creates the verdict.
SKU card stays closed until a dongle we run on this class of Windows host survives lid-close + 30-minute idle without DHCP loss, with the GitHub public repo reachable. Criteria page is live so operators stop buying dock-checkbox Ethernet and calling it a fallback.

Architecture we recommend

  • Laptop PD from the dock. Displays from the dock. NIC on a powered hub that stays up if the dock blinks.
  • Prefer the wired interface as Windows’ metric-0 route. WiFi is fallback, not primary, on an operator desk.
  • Do not VPN-hairpin a public GitHub Pages push. The public repo is public.
  • A hung git push is still a credential prompt. Wiring the NIC does not paste tokens. See Git + Node pack.

Soak test (what “passes” means)

  1. Disable WiFi. Browse the live Pages home. canvas#field still loads.
  2. Idle 30 minutes. Link light stays. ipconfig still has a lease. No “unidentified network” dance.
  3. Unplug/replug the dongle. Hub devices (storage, keys) do not re-enumerate.
  4. Lid close 60 seconds, open. NIC is back without a driver reinstall.
