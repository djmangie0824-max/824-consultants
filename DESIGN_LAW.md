# DESIGN-UI PERMANENT LAW
**824 Consultants LLC / Lexxii · Douglas James Mangie II**  
Locked 2026-08-04 · Non-negotiable

## Law
1. Every public surface uses a single token system (background, elevated, border, signal, warn, muted).
2. No generic AI-slop: no purple gradients, no emoji icons as decoration, no placeholder gray boxes.
3. Typography: one system font stack, fluid scale, tight tracking on display, 1.5 body line-height.
4. Mobile-first. No horizontal overflow. Tap targets ≥ 44px.
5. Disclosure always visible on commercial pages.
6. Cards over walls of text. One primary action per section.
7. Motion only where it informs (hover, focus) — never decorative noise.
8. Public property stays fast, crawlable, and original-content first.
